# X Coin (XFER)

This directory is **not** a substitute whitepaper for X Coin.

X Coin is specified by:

- [README.md](../README.md) — product identity and build
- [docs/LAUNCH.md](../docs/LAUNCH.md) — private-test runbook
- [docs/LOTTERY.md](../docs/LOTTERY.md) — lottery consensus
- [docs/ASSETS.md](../docs/ASSETS.md) — identity roots, subs, uniques
- [docs/FORK.md](../docs/FORK.md) — legal copyright and historical opcode notes

The imported v4.8.0 tree was a use-case-focused UTXO chain with a native
asset layer. X Coin keeps that asset engine (simplified), removes mining,
and produces blocks with a minute lottery among verified-X nodes.

Do not treat historical imported papers or `about` drafts as current
product copy. Required copyright notices stay in [COPYING](../COPYING)
and source headers.
