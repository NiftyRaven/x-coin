# X Coin whitepaper

This directory **is** the X Coin whitepaper.

**Read the paper:** [XCOIN.md](XCOIN.md)

**Nifty Raven** (@NFTRVN on X)

---

X Coin (ticker **XFER**, subunit **xferon**) is a peer-to-peer cash and
asset ledger for people on X. There is no mining. Blocks are produced
by a minute lottery among **X Verified** (blue check) active nodes.
Launch is a **fair launch**: no premine, no founder allocation.

[XCOIN.md](XCOIN.md) is the product paper: motivation, lottery and
issuance, fair-launch supply, Sign in with X versus the 12-word seed,
assets, network, wallets, privacy, and provenance. It is written to
stand alone. Deep mechanics stay in the technical annexes
([lottery](../docs/LOTTERY.md), [Sign in with X](../docs/XSIGNIN.md),
[wallet](../docs/WALLET.md), [fork notes](../docs/FORK.md),
[go-live](../docs/GO-LIVE.md)).

Packaged Linux and Windows wallets are on
[GitHub Releases](https://github.com/NiftyRaven/x-coin/releases).
Download those assets. Do not use **Code → Download ZIP** — that is
the source tree, not a wallet.
