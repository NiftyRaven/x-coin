# X Coin 1.0.18 Light

**Light** wallet. Simple Home. Same chain as **1.0.18 Heavy**. Consensus unchanged.

Sign in with X uses the Client ID shipped in this zip. That packaged id wins over an older `xoauthclientid=` left in `~/.xcoin/xcoin.conf`. The one-hour Sign in lock starts only after a browser actually opens.

Do **not** use Code → Download ZIP.

Windows: X-Coin-1.0.18-Windows.zip
Linux: X-Coin-1.0.18-Linux-x86_64.tar.gz
