# X Coin 1.0.22 Heavy

Wallet and Qt UI only. Consensus unchanged. Not packaged in this change.

- The sync banner and other wallet copy say XFER / X Coin.
- Balances (legacy) shows available, pending, immature, and total XFER, readable assets, recent transactions, and a quiet lottery line. Light and dark both use the same card layout.
- The balance card shows the public NeoxEX XFER/USDT price and the wallet total in USDT when that ticker answers. No API key.
- Send and Balances clear the recipient, amount, and coin draft after a successful send.
- Coin control opens the existing coin picker on both send paths. Off leaves automatic selection.
- Home uses the X Coin mark from xferchain.net.
