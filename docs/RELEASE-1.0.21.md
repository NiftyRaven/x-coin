# X Coin 1.0.21 Light

Wallet and copy only. Consensus unchanged.

- Help links to https://xferchain.net and the community Discord.
- Options → Display → Third party transaction URLs defaults to `https://explorer.xferchain.net/#/tx/%s`. A saved custom URL is kept.
- Help → Command-line options lists the options this wallet accepts.
- About shows X Coin (XFER) 1.0.21.
- Re-link stays optional. Sign in and Re-link share a 5 minute wait after an attempt. The session still lasts until you quit the wallet.

**Light** wallet. Simple Home. Same chain as Heavy. No Market.

Do **not** use Code → Download ZIP.

Windows: X-Coin-1.0.21-Windows.zip
Linux: X-Coin-1.0.21-Linux-x86_64.tar.gz
