# X Coin 1.0.19 Heavy

**Heavy** wallet. Market and tree nav. Same chain as **1.0.19 Light**. Consensus unchanged.

Linux Sign in with X starts the browser without the wallet's bundled libraries. `xdg-open` and `kde-open` no longer inherit `LD_LIBRARY_PATH` from the launcher, which was closing the browser before a window appeared.

The one-hour Sign in lock starts only after a browser helper launches.

Do **not** use Code → Download ZIP.

Windows: X-Coin-1.0.19-Windows.zip
Linux: X-Coin-1.0.19-Linux-x86_64.tar.gz

https://github.com/NiftyRaven/x-coin/releases/tag/v1.0.19
